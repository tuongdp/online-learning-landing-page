# Online Learning Landing Page

An online learning landing page built based on a Figma design.

## Design

Figma: [Online Learning Landing Page](https://www.figma.com/design/lDUxyXqCW0OVUMCWDGEEkq/02.1.-Online-Learning-Landing-Page?node-id=5-251&m=dev)

## Technologies

- HTML5
- CSS3

## Features

- Clean and modern user interface
- Online learning platform layout
- Responsive layout
- Organized CSS styles
- Course showcase section
- Navigation and landing page sections

## Getting Started

1. Clone the repository.
   git clone https://github.com/tuongdp/online-learning-landing-page.git

2. Open the project folder in Visual Studio Code.
3. Open index.html in your browser or use the Live Server extension.

## Purpose

This project was created to practice converting a Figma design into a website using HTML and CSS.
